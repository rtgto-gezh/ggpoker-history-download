# 使用说明

**[English](../en/usage.md)** | 中文

「GGPoker记录下载助手」是一个 Chrome 扩展，帮你把 PokerCraft 上的游戏概要和手牌历史批量下载到本地。扩展负责选日期、分批、跟进每一批的结果；每批的下载按钮需要你点一下。

## 1. 安装

三种方式任选一种。

### 方式一：Chrome 网上应用店（最省事）

1. 在 Chrome 网上应用店搜索「GGPoker记录下载助手」
2. 打开详情页，点「添加到 Chrome」
3. 在弹出的确认框里点「添加扩展程序」

### 方式二：从实时GTO 客户端安装

1. 打开实时GTO 客户端，进入「GG数据导入」
2. 点「安装GG数据下载扩展」，客户端会解压出安装包并告诉你位置
3. 接着按下面方式三的第 2 步往下做

### 方式三：手动安装（开发者模式）

1. 到本仓库的 Releases 页面下载最新的 zip 包，解压到一个不会随手删掉的目录
2. 地址栏输入 `chrome://extensions/` 回车
3. 打开右上角的「开发者模式」
4. 点「加载已解压的扩展程序」，选中**直接包含 `manifest.json` 的那个文件夹**

**这一步最容易装错**：要选的是直接放着 `manifest.json` 的那一层。选成它的上一级（解压时多套了一层目录）或者下一级（放界面文件的那个子目录），Chrome 都会报错装不上。

## 2. 登录与授权

扩展需要授权账号才能使用。

1. 点扩展图标打开侧边栏，首次使用会看到登录界面
2. 输入用户名和密码，点「登录」
3. 勾选「记住密码」后，下次打开会自动登录
4. 要换账号，点侧边栏右上角的「退出」

还没有账号？点登录界面上的「注册账号」，或者到 RtGTO 官网注册。

## 3. 主界面怎么看

登录之后，侧边栏从上到下是这几块：

| 位置 | 内容 |
| --- | --- |
| 顶栏 | 「RtGTO官网」链接、中英文切换、退出 |
| 同步卡片 | 卡片标题是当前牌局页面的名字，旁边有徽标：「概要 + 手牌」「仅手牌（无概要）」或「未识别页面」 |
| └ 已同步至 | 这一类已经同步到的日期，下次会从这天之后接着往下 |
| └ 上次数据同步 | 上一次实际跑同步的时间 |
| └ 本次将同步 | 这次要下载的日期区间和天数（自动算出来的） |
| └ 日期间隔 | 每一批覆盖几天。显示「自动」，由扩展决定，不需要你设置 |
| 按钮 | 「开始同步」（运行中变成「停止」）和「暂停」（暂停后变成「继续」） |
| 清除同步记录 | 清掉当前分类的进度，下次从头同步 |
| 下载核对 | 和本机实时GTO 客户端的连接状态、核对结果，见第 6、7 节 |
| 运行日志 | 扩展每一步做了什么，见第 8 节 |
| 注意事项 | 折叠起来的五条使用须知 |

## 4. 开始同步

1. **先打开一个牌局页面**。在 PokerCraft 打开锦标赛 MTT、极速现金局、德州扑克现金局或奥马哈 PLO 中的一个。扩展要看到页面才知道同步哪一类；没识别出来时，卡片上会显示「未识别页面」，点同步会提示「没有识别出当前分类」
2. 点「开始同步」

之后扩展会自己把事情安排下去：

- **同步区间和批次跨度均自动决定，无需手动设置**——从「已同步至」的次日算到今天，每批覆盖几天由页面列表的加载情况决定
- 每一批开始时，扩展会把日期范围选好，并**高亮下载按钮一直等你点击，不点不会继续**
- 你点完下载，这一批结束后自动进入下一批，直到同步完

同步过程中：

- 「暂停」停下来，再点一次「继续」
- 「停止」终止本次同步
- 卡片上的进度显示当前处理到第几天

**中断了不用担心重复**：已经同步过的日期不会重复下载，下次开始会从断点继续。

想从头算起，点「清除同步记录（下次从头同步）」，把当前分类的进度清掉，再重新开始即可。

## 5. GGPoker 自身的下载限制

有两件事不是工具能决定的，而是 GGPoker 自己的规则：

- **游戏概要**：最多可下载最近 **12 个月**内的 **500 场**。
- **手牌历史**：最多可下载最近 **3 个月**内的 **20,000 手**。

还要注意一点：**四类牌局里只有锦标赛 MTT 有游戏概要**。极速现金局、德州扑克现金局、奥马哈 PLO 这三类只有手牌，界面上会标成「仅手牌（无概要）」，并提示「此类型只有手牌详情，最多回溯 3 个月」。

把上面两条合起来看：

- **锦标赛 MTT**：最近 3 个月有概要有手牌；3 个月到 12 个月之间只有概要；更早的取不到
- **其它三类**：只有最近 3 个月的手牌，更早的日期什么都取不到

这不是工具故障，是数据来源本身的限制。单次记录超过上限时，扩展会自动拆成几趟下载，你不需要手动拆分。

## 6. 下载核对与补下载

扩展只能确认你**点了**下载按钮，没法确认文件是不是真的下到了——网络中断的时候下载会静默失败。所以每一段日期的处理结果都会记在「下载核对」卡片里。

**导出与导入**都藏在卡片里的「更多操作」折叠区，点开就能看到：

- 「导出 JSON」/「导出 CSV」：把下载记录存成文件备查
- 「导入核对结果」：如果你用别的工具核对过完整性，把结果导进来
- 「清空记录」：清掉下载记录（不影响同步进度）

**补下载是自动的，不需要你点**。同步结束时会先核对一遍，缺失的日期段会在**下次点「开始同步」时自动补下载**，不影响已有的同步进度。卡片上会提示还有几段多少天要补：

> 下次点「开始同步」时，同步完会自动补下载这 N 段（M 天）。

已经超出 GGPoker 保留期的日期补不回来，卡片上会写明是哪些。

## 7. 与本机实时GTO 联动核对（可选）

这台机器上装了实时GTO 客户端的话，可以让它帮你核对下载结果。

1. 打开实时GTO 客户端，进入「GG数据导入」
2. 侧边栏的「下载核对」会自动连上；显示未连接就说明客户端没打开
3. 每轮同步结束后，客户端会逐个检查文件下到了没有、能不能读、内容类型对不对，并把结果回传到侧边栏

核对结果的含义：

| 结果 | 含义 |
| --- | --- |
| 已下到并导入 | 一切正常 |
| 条数对不上 | 文件里的场次或手数和下载按钮上显示的对不上 |
| 还在下载 | 文件还没下完 |
| 被中断 | 下载被中断了 |
| 没检测到下载 | 点了按钮，但没有对应的下载发生 |
| 文件不在 | 记录里有，但文件找不到了 |
| 文件读不了 | 文件损坏或格式不对 |
| 内容类型不对 | 下到的不是想要的那一类记录 |

没下到的日期会进入补下载清单，按第 6 节说的方式自动补。

## 8. 运行日志与问题反馈

侧边栏底部的「运行日志」记录着扩展每一步做了什么。遇到问题：

1. 点「复制日志」
2. 连同问题描述一起发给客服

日志里有日期、操作和错误原因，比只描述现象有用得多。

## 9. 常见问题

**装了但点图标没反应？**
先确认当前页面在 `my.pokercraft.com` 上——扩展只在这个站点生效，其它网站（包括 ggpoker.com）点了不会有反应。再确认 Chrome 版本是 114 或更高。

**卡片显示「未识别页面」，点同步提示「没有识别出当前分类」？**
扩展需要先看到你在哪一类牌局页面上。请在 PokerCraft 打开锦标赛 MTT、极速现金局、德州扑克现金局或奥马哈 PLO 中的一个页面，再打开侧边栏。

**为什么只有最近 3 个月有手牌详情？**
这是 GGPoker 自己的限制，见第 5 节。更早的日期要么只有概要（仅锦标赛 MTT），要么什么都取不到（其它三类）。

**同步中途停下来了？**
扩展在等点击——每一批都要你点页面上的下载按钮，不点不会继续。点完自动进入下一批；想中断就点「停止」。

**下载中断了怎么办？**
重新点「开始同步」即可。已经同步过的日期不会重复下载，会从断点接着跑。

**怎么拿到授权账号？**
在 RtGTO 官网注册。

**会不会上传我的数据？**
账号信息和下载记录只存在本机浏览器里。除了登录校验，扩展不会把你的数据传到服务器。

**换电脑要重装吗？**
要重装扩展。账号是通用的，登录后即可使用；但本地的下载记录和同步进度不会跟着走。

**下载的文件在哪？**
在浏览器的默认下载目录里。

## 10. 注意事项

界面底部「注意事项」里的五条，这里抄一遍：

1. 下载过程中鼠标请勿频繁操作页面
2. 若遇到异常、卡顿、操作无反应，请刷新页面后重新操作
3. 每批都会高亮下载按钮并一直等你点击，不点不会继续；要中断请点「停止」
4. 本插件支持锦标赛、极速现金局、德州扑克、奥马哈（PLO）四种游戏
5. 同步区间和批次跨度均自动决定，无需手动设置
